# وصل الإسلامية — Wasl Islamic
## المنصة الإسلامية المتكاملة والموثوقة (Premium Arabic-First Islamic Platform)

منصة وتطبيق إسلامي شامل ومستقل تماماً مبني بأحدث معايير هندسة البرمجيات والتصميم العصري الفاخر، مصمم كمنصة ويب حديثة وتطبيق ويب تقدمي (PWA) فائق السرعة متوافق مع كافة الهواتف الذكية والحواسيب والأجهزة اللوحية دون أي تبعيات أصلية أو حزم APK خارجية.

---

## 🌟 نظرة عامة على مميزات التطبيق

1. **القرآن الكريم والتلاوات المباركة:**
   - فهرس كامل لكافة سور القرآن الـ 114 بالأسماء الرسمية وبيانات النزول (مكية / مدنية) وعدد الآيات والأجزاء.
   - نصوص قرآنية بالرسم العثماني المعتمد مع ترقيم الآيات ورموز نهايات الآيات.
   - التفسير الميسر المعتمد وترجمة معاني الآيات باللغة الإنجليزية (Saheeh International).
   - مشغل صوتي متقدم يضم كبار القراء (مشاري العفاسي، عبد الباسط عبد الصمد، الحصري، ماهر المعيقلي، سعد الغامدي).
   - وضع التحفيظ والتسميع الذاتي (إخفاء الآيات للاختبار، تسجيل صوت القارئ عبر الميكروفون والاستماع إليه).

2. **أوقات الصلاة والقبلة الفلكية:**
   - حساب دقيق للمواقيت (الفجر، الشروق، الظهر، العصر، المغرب، العشاء) وفق معيار تقويم أم القرى.
   - عدّاد تنازلي حي ومباشر حتى موعد الصلاة القادمة.
   - بوصلة إلكترونية تفاعلية تحدد اتجاه القبلة نحو الكعبة المشرفة بمكة المكرمة بالدرجات الزاوية ومستشعر حركة الجهاز.

3. **مخطط الختمة القرآنية:**
   - وضع ومتابعة خطط الختم (30 يوماً لرمضان، 60 يوماً، أو مدة مخصصة).
   - حساب الورد اليومي التلقائي وتتبع الصفحات (من أصل 604 صفحة) وحفظ التقدم محلياً وسحابياً.

4. **موسوعة المعرفة والعبادة:**
   - أذكار حصن المسلم مع مسبحة إلكترونية تفاعلية، واهتزاز تفاعلي عند إتمام العدد.
   - رياض الأحاديث النبوية الصحيحة من صحيحي البخاري ومسلم مع ذكر الراوي والمصدر والتخريج.
   - أسماء الله الحسنى الـ 99 مع بيان معانيها الشرعية وشواهدها القرآنية.
   - دليل مناسك العمرة خطوة بخطوة بالأدعية المأثورة والسنن.
   - حاسبة الزكاة الشرعية الدقيقة (الذهب، الفضة، السيولة، وعروض التجارة مع فحص النصاب).
   - مسابقة ثقافية إسلامية تفاعلية بأسئلة موثقة وشروحات شرعية.
   - إذاعات القرآن الكريم الحية والمباشرة (إذاعة القاهرة، إذاعة مكة، وتلاوات خاشعة).

5. **استوديو البطاقات الدعوية:**
   - توليد بطاقات دعوية عالية الدقة عبر HTML5 Canvas بدقة 1080px.
   - قوالب لونية متعددة: الزمردي الإسلامي، الذهبي الملكي، الليلي الحديث، اليوم الوطني السعودي، والعاجي الهادئ.
   - أبعاد متعددة: مربع (1:1)، عمودي (4:5)، ستوري (9:16)، وعرضي (16:9).
   - تصدير بضغطة زر: تحميل PNG، نسخ كصورة للحافظة، ومشاركة عبر Web Share API.

6. **الهوية البصرية والسمات:**
   - دعم الوضع النهاري (Light)، الوضع الليلي (Dark)، وسمة اليوم الوطني السعودي (Saudi National Day Theme).
   - دعم كامل للغة العربية (RTL) مع إمكانية التحويل للغة الإنجليزية.

## 🌐 بنية المنصة ونشر الويب (Web-Only & PWA Architecture)

منصة ويب متكاملة ومستقلة 100%:
- مبنية بأحدث إصدار من **Next.js 16** مع محرك Turbopack وTailwind CSS v4.
- جاهزة للنشر على منصات Vercel أو Cloudflare Pages أو أي خادم Node.js / Nginx مستقل.
- تدعم تقنية **Progressive Web App (PWA)** عبر `manifest.json` وأيقونات متجاوبة لتكون قابلة للتثبيت المباشر على جميع شاشات الهواتف الذكية (Android و iOS) والأجهزة اللوحية والحواسيب عبر المتصفح دون الحاجة لمتاجر التطبيقات أو حزم APK مقيدة.

## 🛠️ أوامر التشغيل والبناء (Commands)

```bash
# 1. تشغيل خادم التطوير المحلي
npm run dev

# 2. تشغيل حزمة الاختبارات الآلية الشاملة
npm test

# 3. بناء وتصدير نسخة الإنتاج للويب
npm run build

# 4. تشغيل خادم الإنتاج
npm start
```

## 🗄️ إعداد قاعدة بيانات Supabase (اختياري)

التطبيق يعمل بنسبة 100% بدون أي إعدادات خارجية بفضل نظام التخزين المحلي التلقائي (Local Storage & IndexedDB Fallback).

في حال الرغبة بربط قاعدة بيانات Supabase لمزامنة الحسابات السحابية:
1. أنشئ مشروعاً جديداً في [Supabase](https://supabase.com).
2. افتح محرر SQL (SQL Editor) وقم بتنفيذ السكربت الموجود في `supabase/schema.sql`.
3. انسخ بيانات الاتصال إلى ملف `.env.local`:
   ```env
   NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
   NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
   ```
